# Headset shell

The 3D-printed shell that holds the phone in front of the wearer's eyes. The root README section "What the print needs" lists the requirements: 45 mm biconvex lenses, a camera cutout, a finger slot for push-to-talk, a divider between the eyes, vents, a strap, and a "camera on" notice.

What goes in this folder:

- The STL files, or a link to the model if we print an existing Cardboard-style design.
- Slicer settings: printer, material, layer height, infill, supports, and print time.
- Lens measurements: focal length, diameter, and the distance between the lens centers. The `/headset` calibration sliders need that last number.
- The phone the shell fits, with its case off, and where its rear camera sits.
